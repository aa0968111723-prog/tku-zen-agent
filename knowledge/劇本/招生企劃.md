# 任務劇本：招生企劃

## 什麼時候用這份劇本

使用者說「招生企劃」「招生策略」「怎麼招新生」「這學期要招幾個人」「路宣怎麼排」時。

## 產出什麼

通常是**一份文件（create_document）＋一份試算表（create_spreadsheet）**：
文件講策略與文案，試算表管人力、時程與名單。兩個都做，不要只做一個。

## 文件必備章節

1. **本學期招生目標**
   - 目標出席人數（期初茶會、期初演講各自設定）
   - 目標入社人數
   - 提醒：本社的說法是「願力目標」——出發前先發願，有願就有力。
2. **招生管道與分工**（四大管道，缺一不可）
   | 管道 | 做什麼 | 負責組別 |
   |---|---|---|
   | 路宣 | 校內外定時出隊擺攤、發文宣、貼海報 | 招生組＋全社輪班 |
   | 個接（個別接引） | 一對一真心關心與邀請 | 全體社員 |
   | 網宣 | 招生影片、限動、社群經營、倒數 | 網宣組 |
   | 體驗禪 | 固定時段開放體驗，讓人親身感受 | 活動組＋師資 |
3. **主力入口活動**：期初茶會 → 期初演講 → 正式社課承接。
   說明每一關要把人帶到下一關的方法（例如茶會結束當場收報名、演講後加 LINE 個接）。
4. **時程表**：開學前 2 週到期中，逐週列出要做什麼。
5. **人力分工**：哪一組負責哪一段。
6. **文案範例**：直接可用的路宣開場白、限動文案、個接訊息範本、海報標語（至少各 2 則）。
7. **預算概估**：文宣印製、手作材料、場地、茶點。

## 招生文案的寫法（很重要）

**訴求要翻譯成大學生的語言**，不要用社團內部語彙對外：

| 我們內部說 | 對新生要說 |
|---|---|
| 禪定、印心禪法 | 靜下來的方法、專注訓練、大腦休息 |
| 凝聚、家族 | 一群一起變好的夥伴、有人陪你聊 |
| 護持、發願 | 互相幫忙、把事情做成 |
| 靈性成長 | 更了解自己、找到方向 |

可以直接用的訴求關鍵字：認識自己、紓解壓力、提升專注、改善人際、找到方向、
交到一群一起變好的朋友。

**絕對不要寫**：治療焦慮／憂鬱、保證成績進步、改運、開智慧、宗教入門。

## 試算表要有哪些工作表

- **招生時程**：週次、日期、工作項目、負責組別、產出、完成狀態
- **路宣排班**：日期、時段、地點、出隊人員、器材、當日接觸人數、留資料人數
- **名單追蹤**：姓名、系級、認識管道、聯絡方式、接觸紀錄、目前狀態（有興趣／已邀約／已出席／已入社）、負責個接的人
- **文宣製作**：品項、規格、數量、負責人、截止日、狀態

日期一律留空或填「待填」，除非使用者給了確切日期。名單工作表只放欄位標題與 1–2 列
範例格式，不要編造人名。

## 常見錯誤

- 只寫策略不給文案 → 幹部拿到還是不知道怎麼開口，一定要附可直接照念的範例。
- 把四大管道寫成三個或兩個 → 路宣、個接、網宣、體驗禪要齊。
- 用宗教語言寫對外文宣。
- 編造社課時間地點與報名連結。
