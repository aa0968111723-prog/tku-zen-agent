# 任務劇本：社課排程與籌備

## 什麼時候用這份劇本

使用者說「社課排程」「這學期社課要上什麼」「排課表」「社課流程」「一籌二籌」
「社課教案」「帶課要準備什麼」時。

## 一、學期社課排程表（create_spreadsheet）

一學期通常抓 **16–18 週**。欄位固定用這一組：

```
週次,日期,社課主題,類型,師資/帶課者,場地,需準備器材,負責組別,備註
```

- **日期**：使用者沒給就填「待填」，不要自己算。
- **類型**：期初茶會／期初演講／一般社課／期中演講／期末社大／戶外活動／停課。
- **場地**：歷年用過 H116、H117、H118、H119、SG402、E308。沒指定就填「待借」。

### 學期骨架（照這個順序排）

| 位置 | 內容 |
|---|---|
| 第 1 週 | 期初茶會（體驗禪＋手作，招生第一槍） |
| 第 2–3 週 | 期初演講（生命靈數等主題，第二個招生入口） |
| 第 3–8 週 | 一般社課，從「認識自己」「情緒壓力」這類低門檻主題開始 |
| 期中 | 期中演講 |
| 期中後 | 進階主題（禪定方法、潛能、職涯） |
| 倒數第 1–2 週 | 期末社大（感恩送舊） |
| 寒/暑假 | 青年領袖禪訓營（寒）／暑期挑戰營（暑） |

**排課原則**：新生剛入社時排低門檻、生活化的主題（情緒、壓力、人際）；
禪法概念較深的主題（靈性進化論、禪的四度空間）排在學期中後段，等關係建立了再上。

社課主題請從知識庫 §9 的主題庫挑，不要自己發明主題名稱；
真的需要新主題時，用「§9 的命名風格」寫（口語、有畫面、對到大學生的痛點）。

## 二、單堂社課流程表

一堂社課的標準時間軸（可依實際調整，但順序不要動）：

| 時間 | 項目 | 負責 |
|---|---|---|
| 17:30 | 工作人員集合 | 全體幹部 |
| 17:30–18:10 | 用餐＋場佈（桌椅、音控、投影、簽到桌） | 場務組、生活組 |
| 18:10–18:30 | 禪定凝聚（幹部先靜下來） | 社長帶 |
| 18:30 | 社員報到 | 生活組 |
| 18:30–18:40 | 主持人開場、介紹師資 | 活動組 |
| 18:40–20:00 | 師資上課（約 75 分鐘） | 師資 |
| 20:00–20:15 | 社團／活動介紹、宣傳 | 活動組／網宣組 |
| 20:15–21:20 | 凝聚分享（各家族座談）★社團的靈魂 | 家族長／組輔 |
| 21:20–21:40 | 場復、幹部檢討 | 全體 |

## 三、籌備 SOP

- **一籌（社課前三天）**：確認主題與內容、確認講師、確認場地、開始宣傳。
- **二籌（社課前一天）**：確認主講者到場時間、跑一次細流、討論課後凝聚要問什麼問題、器材點收。
- **當天**：照上面的時間軸走。
- **課後**：出席統計、凝聚分享的觀察紀錄（誰需要多關心）、器材歸還。

## 四、凝聚分享的引導問題

每堂社課後家族長要帶討論。做教案時要**附 3–5 題引導問題**，扣回當堂主題。
例如主題是〈找回快樂的自己——情緒管理一把罩〉：

- 這禮拜有沒有哪個瞬間，情緒突然上來？當下你怎麼處理？
- 今天講師講的方法裡，哪一個你覺得自己做得到？
- 如果下次同樣的情況再發生，你想試試看什麼？

問題要**具體、可回答、不評價**，不要問「你對禪定有什麼看法」這種空題。

## 五、器材清單（一般社課的基本盤）

投影機／HDMI 線、筆電、簡報筆、音響／麥克風、延長線、簽到表、名牌、
筆、海報架、坐墊（禪定用）、茶水、講師禮、相機。

## 常見錯誤

- 排程表沒有「凝聚分享」那一段 → 那是社團最核心的環節，不能省。
- 把期初茶會排在第 3 週之後 → 招生第一槍要在最前面。
- 教案只有講師內容，沒有凝聚引導問題。
- 編造講師姓名。師資欄位沒資訊就填「待邀」。
