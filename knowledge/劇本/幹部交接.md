# 任務劇本：幹部交接與傳承

## 什麼時候用這份劇本

使用者說「交接」「傳承」「新幹部要知道什麼」「幹部手冊」「職掌」「幹部訓練」時。

## 語氣

這是**對內文件**，可以完整使用社團語彙：護持、凝聚、發願、家族、組輔、
路宣、個接、體驗禪、社青。不用像對外文宣那樣淡化禪法脈絡 ——
新幹部本來就該把三層脈絡（學校／基金會／禪法）搞清楚。

## 交接手冊章節

1. **我們是誰**（三層脈絡：淡江學生社團 → 世界領袖教育和平基金會 → 印心禪法）
2. **社團精神**（超越自己成就他人／同心同行同證道／有願就有力／散播光的種子）
3. **一年的節奏**（見知識庫 §11）
4. **各職位在做什麼**（見下表）
5. **社課怎麼跑**（一籌二籌、當天時間軸、凝聚分享）
6. **招生怎麼做**（四大管道）
7. **營隊怎麼辦**
8. **要交接什麼東西**（見下面清單）
9. **常見狀況怎麼處理**

## 各職位職掌（章程職務＋實際運作分組）

| 職位 | 主要負責 | 交接重點 |
|---|---|---|
| 社長 | 統籌全社、對外代表、人力調配、講師聯繫 | 校方窗口、基金會窗口、講師名單與聯絡方式 |
| 副社長 | 協助社長、代理職務 | 分工默契 |
| 總幹事／執秘 | 行政統籌、會議召集、進度追蹤 | 行事曆、待辦系統 |
| 總務（財務／庶務） | 收支、社費、核銷、採買 | 帳本、單據、社費收取名單、學校核銷流程 |
| 場務 | 借場地、布置、音控燈控、拍照、控 PPT | 借場地流程與窗口、器材位置與清單 |
| 活動 | 主持、流程設計、破冰、團康 | 歷年流程檔、破冰活動庫 |
| 公關 | 對外聯繫、講師接待、兄弟社團往來 | 講師接待 SOP、兄弟社團聯絡人 |
| 文書 | 會議紀錄、公文、評鑑資料 | 歷年會議紀錄、評鑑檔案位置 |
| 美編／美宣 | 海報、文宣、名牌、隊服設計 | 設計原始檔、字型、社徽檔、配色 |
| 檔案 | 照片影音歸檔、雲端管理 | 雲端資料夾結構與權限 |
| 網路／網宣 | 社群經營、活動宣傳、招生影片 | FB/IG 帳號密碼交接方式、貼文排程、素材庫 |
| 家長／家族長／組輔 | 帶家族、課前課後凝聚、關心社員 | 家族名單、每個社員的狀況 |

## 交接清單（實體與數位）

**數位**
- 共用雲端資料夾與權限（歷年評鑑、各屆營隊、社課教材、照片）
- FB 粉專「淡江大學領袖禪學社」與 IG 帳號的管理權
- LINE 群組管理權（核心幹部群、社員群、各家族群、網宣組群）
- 社員名冊與聯絡資料（**注意個資，只交給接任者，不要外流**）
- 設計原始檔、社徽、字型
- 歷年社課教材與流程檔

**實體**
- 社辦鑰匙、社辦內器材清冊
- 帳本、單據、發票、印章
- 海報架、名牌、隊旗、剩餘文宣品
- 借用中的學校器材

**關係**
- 校方課外組承辦人
- 基金會／師資聯絡窗口
- 兄弟社團聯絡人
- 畢業社友（領袖會淡大校友會）

## 幹部訓練可以怎麼設計

用「青年領袖十二項特質」當骨架，挑對應的能力做訓練：

| 要訓練的能力 | 對應特質 | 可以怎麼練 |
|---|---|---|
| 主持與開場 | 辯才無礙的口才 | 每次社課輪流主持，事後互相回饋 |
| 帶小組討論 | 協調溝通的能力 | 家族長培訓，練習開放式提問 |
| 專案管理 | 企劃、執行、依進度完成目標 | 讓每個人負責一場活動從頭到尾 |
| 決策與擔當 | 領導統御的能力 | 讓幹部自己決定，社長只在關鍵處介入 |
| 定力 | 要有禪的修養 | 每次幹部會議前先禪定凝聚 |

## 常見錯誤

- 只交檔案不交關係 —— 講師、校方、兄弟社團的窗口沒交接，新幹部會卡住。
- 帳務交接沒有對帳 —— 一定要當面點清並簽收。
- 社員名冊隨意轉傳 —— 個資，只給接任者。
- 編造現任或歷任幹部姓名 —— 一律留「待填」。
