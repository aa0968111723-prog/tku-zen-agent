# 任務劇本：Google 表單設計

## 什麼時候用這份劇本

使用者說「報名表」「問卷」「表單」「意願調查」「回饋單」「收資料」時。
用 `create_google_form` 工具。

## 通則

- **必填要克制**：只有真的不能少的才設必填（姓名、聯絡方式）。太多必填會讓人放棄。
- **開頭先講清楚**：description 要寫「這是什麼、要填多久、資料怎麼用」。
- **個資要說明用途**：問手機、學號、緊急聯絡人時，在 help 欄註明「僅用於活動聯繫」。
- **最後一題留開放**：`paragraph` 題型問「還有什麼想跟我們說的」，常常會收到最有用的回饋。

## 一、新生／入社報名表

| 題型 | 題目 | 必填 |
|---|---|---|
| short_text | 姓名 | ✓ |
| short_text | 系級（例如：資工二） | ✓ |
| short_text | 手機 | ✓ |
| short_text | LINE ID | |
| email | 電子郵件 | |
| multiple_choice | 你是怎麼知道我們社團的？（路宣攤位／朋友介紹／IG 或 FB／社團博覽會／期初茶會／海報／其他） | ✓ |
| multiple_choice | 有靜坐或冥想的經驗嗎？（完全沒有／試過幾次／有固定習慣） | |
| checkbox | 你最希望從社團得到什麼？（放鬆紓壓／提升專注／更了解自己／改善人際／交朋友／挑戰自己／其他） | |
| checkbox | 哪些時段你有空？（列出可能的社課時段） | |
| paragraph | 有什麼想先問我們的嗎？ | |

## 二、營隊報名表

在上面的基礎上加：

| 題型 | 題目 | 必填 |
|---|---|---|
| short_text | 學號 | ✓ |
| short_text | 緊急聯絡人姓名與關係 | ✓ |
| short_text | 緊急聯絡人電話 | ✓ |
| multiple_choice | 飲食（葷／素／不吃牛／其他過敏） | ✓ |
| paragraph | 病史、慢性病、目前用藥、過敏（沒有請填「無」） | ✓ |
| multiple_choice | 隊服尺寸（S/M/L/XL/2XL） | ✓ |
| scale | 體能自評（1 很少運動 – 5 常運動） | |

戶外／登山營隊再加：登山經驗、是否懼高、有無自備登山鞋。

## 三、社課回饋問卷

問卷的重點是**問得出可以改的東西**，不要只問滿意度。

| 題型 | 題目 |
|---|---|
| scale | 今天的社課整體來說（1 沒什麼收穫 – 5 收穫很多） |
| checkbox | 今天哪些部分你覺得有收穫？（講師內容／禪定練習／凝聚分享／認識新朋友／其他） |
| paragraph | 今天有沒有哪一句話或哪個練習，你想帶回去試試看？ |
| paragraph | 今天有沒有哪個部分你覺得可以更好？ |
| scale | 你會想推薦朋友來嗎？（1 不會 – 5 一定會） |
| multiple_choice | 下次還會來嗎？（會／看時間／不確定） |
| paragraph | 想上什麼主題？或想跟我們說什麼？ |

## 四、幹部意願調查

| 題型 | 題目 |
|---|---|
| short_text | 姓名、系級 |
| checkbox | 你有興趣的職位（社長／副社長／總幹事／總務／場務／活動／公關／文書／美編／網宣／組輔／都可以） |
| paragraph | 為什麼想接這個位置？ |
| scale | 下學年你可以投入的程度（1 偶爾幫忙 – 5 全力投入） |
| checkbox | 你會的技能（設計／剪片／攝影／主持／寫文案／記帳／帶團康／其他） |
| paragraph | 有什麼顧慮或需要社團配合的？ |

## 五、活動出席統計

給已經報名的人填的簡短表單：姓名、將出席的場次（checkbox）、
是否需要協助（交通／餐食／其他）。

## 常見錯誤

- 問一堆用不到的資料 → 每一題都要能回答「收到之後我要拿它做什麼」。
- 滿意度問卷只有分數沒有開放題 → 分數改不了任何東西。
- 沒問「怎麼知道我們的」→ 這題直接告訴你哪個招生管道有效，非常重要，不要漏。
- 病史／緊急聯絡人設成非必填。
