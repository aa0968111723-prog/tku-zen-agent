# 任務劇本：經費預算與核銷

## 什麼時候用這份劇本

使用者說「預算」「經費」「花多少錢」「核銷」「收支」「社費」時。

## 產出

一份試算表，通常要三個工作表：**預算表、收支明細、核銷追蹤**。

## 一、預算表

```
類別,項目,單價,數量,單位,小計,經費來源,備註
```

`小計` 欄請用公式（例如 `=C2*D2`），最後加一列總計用 `=SUM(...)`，
這樣使用者改數量就會自動重算。

### 收入類別

| 類別 | 說明 |
|---|---|
| 社費 | 每學期向社員收取（金額每年不同，沒資料就填「待填」） |
| 學校補助 | 課外活動輔導組的社團經費補助 |
| 基金會支援 | 營隊或講師相關 |
| 活動收費 | 營隊費、材料費 |
| 上期結餘 | 前一學期／學年結轉 |

### 支出類別（照這六類分，方便核銷）

| 類別 | 常見項目 |
|---|---|
| 社課 | 講師禮／車馬費、茶點、坐墊、教材印製 |
| 營隊 | 交通、住宿、餐費、保險、場地、隊服、道具、獎品 |
| 文宣 | 海報印製、DM、貼紙、名牌、社徽製作 |
| 器材 | 音響、延長線、投影相關、社辦用品 |
| 場地 | 校內外場地借用費 |
| 雜支 | 郵資、影印、耗材、感謝禮 |

## 二、收支明細

```
日期,項目,類別,收入,支出,餘額,經手人,憑證編號,備註
```

`餘額` 欄用公式累加（第一列 `=D2-E2`，之後 `=F2+D3-E3`）。

## 三、核銷追蹤

```
憑證編號,日期,項目,金額,發票/收據,是否已交,核銷狀態,經辦人,備註
```

核銷狀態：未送件／已送件／已核准／已入帳／退件補件。

## 學校核銷的注意事項

寫預算或核銷相關文件時要提醒的重點：

- **統一編號**：向學校核銷的發票要開學校的統編（實際號碼請使用者確認課外組規定）。
- **單據要正本**：收據、發票正本要留存，不要只拍照。
- **品名要具體**：發票品名寫「文具」通常會被退，要寫清楚品項。
- **講師費**：可能需要領據與身分證影本，且有所得稅相關規定。
- **時限**：活動結束後有核銷期限，逾期不受理。
- 以上細節每年可能調整，**實際規定一律以課外活動輔導組當年度公告為準**——
  不要在文件裡寫死一個看起來很確定的數字或期限。

## 常見錯誤

- 小計與總計用手算填死數字 → 一定要用公式。
- 支出沒分類 → 核銷時會很痛苦。
- 編造社費金額、補助金額、統編 → 沒有就填「待填」或「依課外組公告」。
- 忘了「上期結餘」與「本期結餘」，導致帳接不起來。
