# 任務劇本：營隊籌備（禪訓營／挑戰營）

## 什麼時候用這份劇本

使用者說「挑戰營」「禪訓營」「營隊」「出隊」「行前」「登山」「三天兩夜」時。

## 本社的兩個營隊

| | 青年領袖禪訓營 | 暑期挑戰營 |
|---|---|---|
| 時間 | 寒假 | 暑假 |
| 性質 | 全國性，與各校領袖社／禪學社及基金會合辦 | 本社特色營隊 |
| 天數 | 三天兩夜 | 依屆別（歷屆多為數天） |
| 地點 | 屏東達摩道場、關西禪修中心 | 戶外／山區（如孝子山） |
| 主軸 | 禪定內訓、領袖培養 | 登山與自我挑戰、突破舒適圈 |
| 歷屆 | 第 11、12 屆持續辦理 | 6th 金剛勇士虎戰隊(2022)、7th 金剛勇士虎2.0(2023)、8th 破曉(2024)、9th 登峰傳心(2025)、10th 禪行破浪(2026) |

挑戰營的精神：**在體能與心理的挑戰中突破舒適圈，把禪定的「靜定力」用在真實的挑戰上。**
寫文案時要抓住這個對比 —— 不是單純去爬山，是把平常在社課練的定力拿出來用。

## 產出組合

營隊籌備通常要一整套，建議一次做出來：

1. **籌備進度表**（試算表）
2. **工作分組與職掌表**（試算表，可與 1 同檔不同工作表）
3. **行程表／細流**（試算表）
4. **器材與採買清單**（試算表）
5. **報名表**（Google 表單腳本）
6. **行前通知**（文件）
7. **企劃書**（文件，要送學校或基金會時用）

## 籌備進度表欄位

```
階段,工作項目,負責組別,負責人,開始日,截止日,狀態,備註
```

階段固定分成：**前置（D-60 起）／招生報名（D-45）／確認（D-14）／行前（D-7）／
營期中／結案**。

## 工作分組（沿用社團既有分組）

| 組別 | 營隊期間負責 |
|---|---|
| 總召／社長 | 統籌、對外聯繫、突發狀況決策 |
| 招生組 | 學員招募、名單、繳費追蹤 |
| 活動組 | 關卡設計、主持、破冰、團康 |
| 生活組 | 報到點名、餐飲、住宿分配、學員照顧、聯絡家長 |
| 場務組 | 交通、場地、器材、音控、攝影 |
| 美宣組 | 隊服、海報、名牌、隊旗、紀念品 |
| 網宣組 | 行前宣傳、限動、營期紀錄、成果發布 |
| 組輔／家族長 | 帶小隊、心得分享、學員狀況回報 |

## 行程表（細流）欄位

```
日期,時間,活動項目,地點,主責,支援,器材,備註
```

戶外／登山營隊的細流一定要包含：**集合時間地點、交通、天氣備案、
中途休息點、午餐、預計攻頂／折返時間、下撤時間、緊急連絡**。

## 器材清單分類

行政（名冊、保險單、收據、醫藥箱）／
場地（音響、麥克風、延長線、投影）／
活動（關卡道具、獎品、白板）／
生活（飲水、餐具、垃圾袋、備用衣物）／
登山專屬（頭燈、雨衣、登山杖、行動糧、無線電、GPS、繩索）／
攝影（相機、電池、記憶卡、腳架）。

## 安全事項（戶外營隊必寫，不可省略）

寫戶外／登山營隊的企劃或行前通知時，**一定要包含這一段**：

- 保險：全體投保，保單影本隨隊。
- 醫藥：急救包、常備藥、學員病史與過敏調查（報名表要問）。
- 天氣：雨天／颱風備案與取消判斷標準、決定時間點。
- 分隊：每小隊配置組輔，人數不超過 10 人，前中後押隊。
- 通訊：緊急聯絡人清單、山區收訊備案、無線電頻道。
- 體能：報名時說明體能要求，行前告知裝備清單。

這不是形式 —— 學校社團辦戶外活動，安全計畫是核銷與核准的必要文件。

## 報名表必問欄位

姓名、學校系級、學號、手機、緊急聯絡人與關係、緊急聯絡電話、
飲食習慣（葷／素／過敏）、病史或身體狀況、體能自評、隊服尺寸、
是否曾參加過本社活動、怎麼知道這個營隊的、想從營隊得到什麼。

登山營隊再加：登山經驗、是否有懼高、慣用鞋型。

## 常見錯誤

- 戶外營隊沒寫天氣備案與安全計畫。
- 行程表沒有緩衝時間，排太滿。
- 報名表沒問緊急聯絡人與病史。
- 編造營隊日期、地點、費用 —— 沒有就填「待定」。
