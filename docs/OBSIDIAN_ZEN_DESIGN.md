# 黑曜石禪光設計系統（Obsidian Zen Design）

工作台整體視覺語言：**黑曜石背景＋紅黃綠青高亮光環＋科技禪光**。
吸收「地球與紅黃綠軌道光環」的視覺語言——深色底、發光邊緣、光暈、
立體透明玻璃卡片、光束與軌道感——但不直接複製地球或軌道圖案。
沉靜（禪）與能量（AI 工作台）並存：**每一種顏色都有功能意義，
每個光效都幫助使用者理解狀態。**

實作位置：

- Tokens 與所有元件樣式：`app/static/style.css`
- 禪光 AI 球與背景光效標記：`app/static/index.html`
- 卡片狀態掛點（`data-status`、`data-verified`）：`app/static/app.js`

## 一、色彩 Design Tokens

### 背景層

| Token | 值 | 用途 |
|---|---|---|
| `--bg-main` | `#050607` | 頁面底色（黑曜石） |
| `--bg-deep` | `#090D10` | 更深的面板底（閘門、輸入槽） |
| `--surface` | `#11181D` | 卡片底 |
| `--surface-light` | `#182329` | 浮起表面、輸入框、次要按鈕 |
| `--border` | `rgba(255,255,255,.12)` | 玻璃邊框 |

### 高亮狀態色（唯一允許的彩色來源）

| Token | 值 | 功能意義 |
|---|---|---|
| `--neon-red` | `#FF3045` | 來源衝突／錯誤／禁止直接使用 |
| `--neon-yellow` | `#FFE14D` | 待確認／需要反問／部分驗證 |
| `--neon-green` | `#65F58A` | 已驗證／已完成／通過檢查 |
| `--neon-cyan` | `#53D7FF` | 查詢中／進行中／主要操作／AI 本體 |
| `--neon-blue` | `#62AFFF` | 連結與次要強調 |

### 光暈

| Token | 值 |
|---|---|
| `--glow-red` | `0 0 18px rgba(255,48,69,.55)` |
| `--glow-yellow` | `0 0 18px rgba(255,225,77,.55)` |
| `--glow-green` | `0 0 18px rgba(101,245,138,.55)` |
| `--glow-cyan` | `0 0 18px rgba(83,215,255,.55)` |

### 文字

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | `#EAF2F5` | 主文字 |
| `--ink-2` | `#A7B8C2` | 次要文字 |
| `--ink-3` | `#8296A1` | 弱化文字、時間戳 |

### 彩色使用邊界

彩色**只**用在：狀態、進度、反問卡選取、AI 球、來源可信度、
主要操作、重要提醒。其餘一律灰階玻璃。大面積永遠是黑曜石；
霓虹色以「細線、光點、光環、徽章」出現，不做大色塊。

## 二、光效與狀態規則

### 資訊正確性四色

所有研究結果與 AI 輸出都必須有明確狀態，對應到卡片左側光條、
狀態徽章與光暈：

| 光環 | 狀態 | 意義 |
|---|---|---|
| 綠 | 已驗證 | 來源與研究對象一致，內容有原始證據支持 |
| 黃 | 待確認／部分驗證 | 部分內容有來源，部分仍是推測 |
| 紅 | 來源衝突 | 資料可能混入其他學校或錯誤來源，禁止直接使用 |
| 青 | 查詢中／AI 推測 | AI 正在搜尋比對，或內容為 AI 推測 |

### 光效紀律

- 光暈半徑固定 18px（`--glow-*`），不疊加多層強光。
- 不使用快速閃爍；呼吸與旋轉動畫週期 ≥ 2.4s。
- `prefers-reduced-motion: reduce`：停用所有動畫，狀態只靠顏色與文字。
- `prefers-contrast: more`：拿掉光暈與玻璃透明度，改用實色高對比。
- 背景光效（紅暈、黃束、綠點、青軌道）透明度 ≤ 0.14，
  固定定位不隨捲動、不遮文字；小螢幕（<640px）不做漂移動畫，
  降低低效能裝置負擔。

### 禪光 AI 球（`.ai-orb`）

黑色透明核心＋中央青白光點＋紅黃綠青四圈細光環慢速旋轉。
不卡通、不宗教化——是一顆高級 AI 能量核心。狀態對應：

| 狀態 class | 情境 | 光效 |
|---|---|---|
| `.is-idle` | 等待 | 青色微光呼吸 |
| `.is-asking` | 需要反問 | 黃色光環亮起，標籤「需要你確認」 |
| `.is-thinking` | 查詢外部資料 | 青色與黃色光點沿軌道運行 |
| `.is-complete` | 任務完成 | 綠色與青色光暈擴散一次 |
| `.is-error` | 來源錯誤／需要處理 | 紅色光環脈動 |

## 三、元件規格

### 反問卡（`#preflight-sheet` / `.preflight-options`）

發光選擇面板，不是普通表單：

- 上方顯示「第 1 題／共 3 題」進度（`.question-progress`）。
- 每個選項是玻璃卡片，左側常駐一顆狀態光點。
- 選取後：邊框轉青色、柔和外發光、右側出現勾選光點（`::after`）、
  未選取卡片降低透明度（`:has()` 漸進增強）。
- 底部「下一步／確認開始」為青色發光按鈕。

### 研究來源卡（`.source-card[data-status]`）

玻璃質感＋左側發光色線條＋右上狀態徽章：

| `data-status` | 邊框／光暈 |
|---|---|
| `verified` | 綠 |
| `partially_verified` | 黃 |
| `inferred` | 青 |
| `conflicted`、`wrong_entity` | 紅 |
| `stale`、`insufficient_evidence` | 灰（無光暈） |

內容：來源名稱、狀態徽章、來源日期、原文摘錄（收合）。
操作：開啟來源、查看原文、回報來源錯誤、只看已驗證。

### 工作進度卡（`.timeline` / `.step`）

光環進度軌道，取代密集文字：

- 每一步是軌道上的一顆光點：
  `○` 灰＝等待、`◉` 青發光脈動＝進行中、`●` 綠＝完成、紅＝需處理。
- 標題列顯示「目前進度 n／5」；詳細資料預設收合。
- 介面**禁止**出現內部技術名稱（`create_social_post`、`retrieval`、
  `verification`、`artifact`、API 名稱、Python 錯誤、內部參數）——
  一律經 `humanLabel()`／`TOOL_LABELS` 轉成中文。

### 產出結果卡（`.result-card[data-verified]`）

- 標題顯示乾淨名稱（如「期初茶會 IG 貼文」）；完整檔名放在
  詳細資訊小字，不讓 `_2_2.md` 破壞畫面。
- 狀態光點：`data-verified="ok"` 綠光「已通過檢查」、
  `data-verified="warn"` 黃光「檢查有警告」。
- 顯示內容預覽、格式、版本、來源狀態、待補資料。
- 操作：開啟預覽、複製、下載、修改這份、轉成輪播、轉成 Reels、
  重新產生。

## 四、手機版（320–430px）

- 卡片單欄；光暈不得造成橫向滾動（背景層 `overflow: hidden`）。
- 反問卡選項單欄可單手選擇；主要按鈕亮色但不刺眼。
- 長內容預設收合；來源卡上下滑、輪播卡左右滑。
- AI 球在頂列，不遮輸入框；輸入框與送出鈕維持 44px 觸控目標。
- 驗收：`scripts/mobile_check.mjs`＋`tests/test_mobile_accessibility.py`。
