> - `infer()` 的 hay **不含檔案正文**。正文裡的「績效達人」「智慧的傳承」「無耳茶壺山」若沒出現在 path/label，現行規則吃不到——不把正文命中算進受害檔。

推論順序（與程式相同）：

```text
hay = f"{path.as_posix()} {label}"
meta.activity       = _match_first(hay, ACTIVITY_RULES)
meta.document_type  = _match_first(hay, DOC_TYPE_RULES)
meta.team           = _match_first(hay, TEAM_RULES)
```

`_match_first`：逐條規則找**該條第一個命中的別名**，分數 = `len(別名)`，只在分數**嚴格大於**當前最佳時覆寫。同分時先寫入的規則勝出。
